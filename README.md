# PGM — Personal Game Master

Solo and multiplayer Pathfinder 1e procedural dungeon crawl, with **blind-first accessibility**.

Not an accessibility layer bolted onto a visual game: the audio interface is the primary one, and the screen is the secondary view.

## Credits

Created by **Tobias Merriman** (Folken Games).

Co-developed with **Josh Morrison**, who is blind and plays it. The accessibility design, the rules calls and a great deal of what this gets right came out of his play reports.

Engineering assistance from Claude Code (Anthropic).
